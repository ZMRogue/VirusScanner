# VirusScanner
A Windows Virus Scanner and Cleaner app built with C# and PowerShell.

## Features
- ✅ Scan running processes for malware
- ✅ Check startup programs for suspicious entries
- ✅ Scan temp folders for dangerous files
- ✅ Clean and delete suspicious files
- ✅ Save scan report to Desktop

## How to Use
1. Run `VirusScanner.exe` as Administrator
2. Click **SCAN NOW** to scan your PC
3. Click **CLEAN** to remove threats
4. Click **SAVE REPORT** to save results

## Built With
- C# / .NET 10
- Windows Forms
- PowerShell
